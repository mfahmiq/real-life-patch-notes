## The entry

> v2.1.4: Fixed a bug where the brain replayed an embarrassing moment from 2009 every night at 3 AM, with no skip button and no mute.

131 characters, one line, written in the terse register of a real release
note: a version number, a bug stated as if it shipped, and a punchline
everyone recognises from their own 3 AM.

## How it works

`main.py` is Python 3.13 standard library only — no network, no
dependencies, fully deterministic. It writes the patch note to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) and asserts the
1–160 character bound before writing, so the output is always valid.

## Why this line

The bug is specific and universal at once: a brain that reruns an old
embarrassment on a schedule, with no controls. The fix is stated deadpan,
like a real shipped changelog entry — which is exactly what makes it land.
